    Projekty

      Ukládá se jen seznam projektů (předchozí verze konfigurace zůstane vedle jako .bak). Claude pracuje vždy jen ve vybraném projektu. Složku účtu Claude Code, domovskou složku ani kořen disku přidat nejde.

      Účty

        Účty se z bezpečnostních důvodů upravují jen ručně v local/config.json – každý s očekávaným e-mailem, který aplikace ověřuje. Jiný účet (třeba osobní) tak nejde použít ani omylem.

        Okno

        Také klávesa F11. Spouštět rovnou na celou obrazovku: "startFullscreen": true v configu.

        Oznámení

        Jen když okno není aktivní.
        Kdy upozornit

        Statistiky

        Odhad ceny API = kolik by běh stál při placení za API (hlásí ho Claude Code). S předplatným (Pro, Max, Team) se za běhy neplatí zvlášť – rozhoduje limit účtu (výše). Údaje jsou jen z tohoto okna.

          ↑↓ výběr • Enter použít • Esc zavřít. Příkazy a skilly se načtou z prvního běhu v projektu; vestavěné příkazy terminálu (např. /cost) v aplikaci nemusí fungovat.
