Novou složku přihlásíte tlačítkem Příkaz pro přihlášení: vložte ho do terminálu, spusťte a napište /login.

              Statistiky

              Období

              Odhad ceny API = kolik by běh stál při placení za API (hlásí ho Claude Code). S předplatným (Pro, Max, Team) se za běhy neplatí zvlášť – rozhoduje limit účtu. Toto okno je jen z paměti okna; Historie ukládá jen čísla (žádné texty zpráv) do datové složky aplikace na 180 dní.

                ↑↓ výběr • Enter použít • Esc zavřít. Příkazy a skilly se načtou z prvního běhu v projektu; vestavěné příkazy terminálu (např. /cost) v aplikaci nemusí fungovat.

                Změny v projektu

                Klikněte na řádek (nebo na něm stiskněte Enter, šipky ↑↓ přecházejí mezi řádky) a napište k němu komentář – komentáře pak vložíte do zprávy pro Clauda. Jen pro čtení – commit, push ani jiné změny v gitu se odsud nedělají.

                Přehled sezení

                Podle přepisu sezení, který ukládá Claude Code (jen čtení). Soubory změněné příkazy v terminálu (Bash, PowerShell) tu nejsou – všechny změny ukazuje přehled gitu. Stav MCP serverů hlásí Claude Code při každém spuštění; aplikace nečte jejich nastavení.

                Kontext sezení

                Údaje hlásí Claude Code (jako /context). Zhustit shrne dosavadní konverzaci – Claude si pamatuje podstatné, podrobnosti se ztratí; stojí to jeden dotaz na model.

                Otázka bokem

                Claude odpoví z kontextu otevřeného sezení v režimu Plán (nic nemění). Otázka ani odpověď se do sezení nezapíšou.
